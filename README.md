# MVC Form Data API

This is a Node.js + Express.js project that uses the **MVC architecture** to handle form data with MongoDB as the database. It uses **Mongoose** for object data modeling and includes basic CRUD operations.

## 🚀 Features

- Express.js server setup
- MongoDB integration with Mongoose
- MVC folder structure
- User and Blog route handling
- Environment variable support via `.env`
- Modular code organization

## 🛠 Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- Dotenv
